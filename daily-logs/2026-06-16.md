## Jyne 16 -- Helm

- installed Helm, created ci-lab chart from scratch
- Chart.yml, values.yml, 5 templates (configmap, secret, deployment, service, postgres)
- helm install- one command deploys everything
- helm upgrade --set app.replicas=3 - change values without editing files
- helm history - tracks every revision
- helm rollback ci-lab 1 - instant rollback to any revision
- key insight: values.yaml = single sources of truth for all config
