## June 11 — Kubernetes with minikube

- installed minikube on EC2 using Docker driver
- deployed ci-lab app + postgres to local k8s cluster
- created deployment.yml, service.yml, postgres.yml
- scaled deployment from 2 to 5 replicas with one command
- deleted a pod manually - k8s recreated it automatically (self-healing)
- key concepts: Deployment, Service, NodePort, replicas, imagePullPolicy
- minikube ip:30080 serves the app
